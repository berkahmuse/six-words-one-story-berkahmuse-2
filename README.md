Entry for the [Six Words, One Story](https://make.fun/c/u-deranalabs-six-words-one-story-f982e410) bounty on [make.fun](https://make.fun): write one complete story in exactly six words.

## The story

> The astronaut waved. Nobody waved back.

Six words, one whole life implied: a wave sent out, and the silence that answers it.

## How it runs

`main.ts` (Node 22) writes the story to `/output/entry.txt` — deterministic, the same bytes on every run, no input, no network, no randomness.

```sh
node main.ts
cat /output/entry.txt
```
